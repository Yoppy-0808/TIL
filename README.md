# TIL
- その日の学習を記録していくリポジトリです
- 各言語や分野ごとにディレクトリを分けています

- ## TIL (Today I Learned) 運用ルール
プログラミング学習の記録を、後から「逆引き辞典」として使えるように整理します

### 1. ディレクトリ構造
「言語別 ＞ 技術・カテゴリー別」で管理します。

### 2. ファイル命名規則
ファイル名は短くシンプルに保ち、GitHubの検索機能を活用します

- **形式**: `YYYYMMDD.md`
- **例**: `20250615.md`
- ※ 同一カテゴリーで1日に複数書く場合は `20250615_02.md` とする

### 3. 書き方のひな型
中身の1行目には、何の内容かパッとわかる見出しをつけます

# [2025/xx/xx] 今日の学び：[ここに一言タイトル] 
- 内容を記載
